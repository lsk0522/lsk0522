## 🎯 About Me

서울로봇고등학교 **첨단로봇제어과**를 졸업했습니다.
3년 동안 산업용 로봇, 협동 로봇, 자율주행 로봇, 드론, 임베디드 회로까지 다양한 로봇을 직접 다뤄 왔습니다.

저는 **한 분야에 머무르지 않고 로봇 한 대를 처음부터 끝까지 만드는 것**을 좋아합니다.
Inventor·Fusion으로 기구를 설계하고, OrCAD로 회로와 PCB를 그리고, 직접 납땜한 기판 위에서
ESP32·AVR 펌웨어를 올린 뒤, ROS 2와 OpenCV로 로봇이 스스로 움직이게 만드는 과정 전체를 경험했습니다.

최근에는 **ROS 2와 LeRobot 프레임워크로 SLAM·Nav2 자율주행과 모방학습 기반 피지컬 AI**를 다루고,
결과를 직접 시연 발표했습니다.

대회에서는 **SSRC 마케팅 부문 금상**, **2026 WCRC 자율주행 로봇 시니어 은상(경기도지사상)**,
**지능형로봇경진대회 동상**을 받았고,
메이커페어 서울·로보월드에서 부스를 운영하며 만든 로봇을 사람들에게 직접 설명해 왔습니다.

작업실에서는 **Voron 2.4를 직접 조립·튜닝**하고 여러 대의 3D 프린터를 Klipper로 운영하며,
문제가 생기면 끝까지 원인을 찾아 해결하는 습관을 기르고 있습니다.

로보틱스 관련 모든 경험에 열려있습니다. 편하게 연락 주세요.
